# ITE_BaseDeDatos_RespuestaRapida

## Descripción

El proyecto busca registrar y organizar la información del personal y alumnado del **Instituto Tecnológico de Ensenada (ITE)**, con la finalidad de facilitar la **respuesta rápida ante situaciones de emergencia**.

La base de datos nos permitirá almacenar información relevante de las personas que forman parte de la institución, como datos personales, contactos de emergencia, alergias, padecimientos y otras condiciones que puedan ser importantes durante una situación de emergencia.

## Objetivo

Diseñar una base de datos que permita consultar de manera rápida y organizada información relevante del personal y alumnado del Instituto Tecnológico de Ensenada durante una situación de emergencia.

El sistema busca proporcionar información que pueda servir como apoyo para la atención inicial mientras se solicita y espera la llegada de los servicios profesionales de emergencia.

> **Importante:** Este proyecto no sustituye al servicio de emergencias 911 ni pretende realizar diagnósticos o indicar tratamientos médicos.

## Alcance

El proyecto contempla el registro y organización de información relacionada con:

- Alumnos.
- Personal del instituto.
- Datos de contacto.
- Contactos de emergencia.
- Alergias.
- Padecimientos o condiciones médicas relevantes.
- Información útil para situaciones de emergencia.
- Relaciones entre los diferentes tipos de información.

## Base de datos

La información será organizada mediante diferentes tablas relacionadas entre sí, buscando mantener los datos estructurados, facilitar las consultas y evitar la duplicidad de información.

La estructura de la base de datos se encuentra actualmente en fase de diseño y podrá modificarse conforme avance el desarrollo del proyecto.

## Datos de prueba

Durante el desarrollo y las pruebas se utilizarán **únicamente datos ficticios**.

No se almacenarán ni publicarán datos reales de alumnos, docentes, administrativos o cualquier otra persona perteneciente al Instituto Tecnológico de Ensenada dentro de este repositorio.

## Seguridad y privacidad

Debido a que el proyecto contempla información personal y potencialmente sensible, el acceso a la información deberá estar limitado a personal autorizado.

Este repositorio está destinado al desarrollo académico del proyecto y contendra la estructura, arquitectura y elementos necesarios para su desarrollo, utilizando datos ficticios para las pruebas.
